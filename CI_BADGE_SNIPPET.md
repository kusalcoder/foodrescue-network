# CI badge — add this near the top of your README.md

Replace `YOUR_GITHUB_USERNAME` and `YOUR_REPO_NAME` with your actual
GitHub username and repository name once this is pushed:

```markdown
![Tests](https://github.com/YOUR_GITHUB_USERNAME/YOUR_REPO_NAME/actions/workflows/tests.yml/badge.svg)
```

This renders a small "passing"/"failing" badge that updates
automatically after every push, so anyone visiting your repo (or you,
at a glance) can see the current test health without opening the
Actions tab.
